Delivered as a web console, HTTP API (OpenAPI), TypeScript SDK, pf CLI, three template contracts and a reference receiver.

The demo scenario walks this loop: a user requests a job on JobRegistry, the indexer picks up JobRequested, the workflow calls an idempotent service, completes the job on-chain once, and registers evidence.
