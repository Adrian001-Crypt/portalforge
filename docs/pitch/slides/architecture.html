reviveApi runtime calls

Services

indexer — EVM + native streams
worker — router, scheduler, engine, executor, monitor
API — auth, RBAC, OpenAPI

Interfaces

Web console
TypeScript SDK · pf CLI
Idempotent receivers (demo service)

Shared state: SQLite (WAL)

Every multi-step write is one BEGIN IMMEDIATE transaction: cursor + events together; leases and state changes guarded by owner and expiry.

Least privilege

The API holds no chain key. The worker’s executor only calls allowlisted, nonpayable functions within a fee and rate budget.

Single-host design today: one database file, many processes. A hosted, multi-tenant version would move the store to PostgreSQL; the store interface was kept narrow for that.
