PortalForge

Open-source middleware for Portaldot V3: deploy and verify contracts, index EVM and native events together, run workflows that survive failures, and check the results on-chain.

Current status: deployed on the Portaldot V3 testnet, with two full jobs completed and their evidence verified on-chain. JobRegistry 0xd5dcf5a7d69354b07f776f8a961348f0a394d746, EvidenceRegistry 0xf005d9e544a399196473ec167eda85c089d80cff. All transactions.

Run it yourself

git clone https://github.com/Adrian001-Crypt/portalforge.git && cd portalforge
npm ci
npm run contracts:build
npm run dev   # console on http://localhost:5180

Needs Node 24 or later and Foundry. Details in the README.
